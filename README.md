# Explorer / Rosmaster

Единственная поддерживаемая конфигурация проекта — ручное управление Rosmaster с MacBook через локальную сеть.

## Что работает

- веб-панель по адресу `http://explorer.local:8080` или по текущему IP робота;
- управление шасси и рукой с клавиатуры;
- управление шасси и рукой с USB-геймпада;
- живая камера;
- состояние двух лидаров, IMU, одометрии, питания и контроллера;
- аппаратно-безопасный STOP и watchdog;
- служебная прошивка контроллера в каталоге `firmware/`.

Экранные стрелки, управление суставами по градусам, автономность, обучение, голос, помощник, ИИ-агент и навыки в проект не входят.

## Запуск на роботе

```bash
sudo ./bin/install-services.py
```

После запуска должны работать только службы `explorer-mcu`, `explorer-watchdog`, `explorer-control`, `explorer-power`, `explorer-camera`, `explorer-camera-cache` и `explorer-web`.

## Безопасность

Перед первым физическим тестом поставьте робота на свободную площадку. Панель начинает движение только после выбора источника управления, включения ручного режима, подтверждения присутствия и снятия STOP. Потеря вкладки, источника команд или свежих данных приводит к остановке.
