# Explorer — установлен на Jetson

Рабочий каталог: `/home/vlad/Explorer`. Основные процессы работают локально.
**Это незавершённый этап ввода в эксплуатацию, не готовый автономный манипулятор.**

## Управление

Открыть `http://explorer.local:8080` или `http://192.168.0.177:8080`.
Команда `~/Explorer/bin/explorer url` выводит ссылку с ключом доступа.
Ключ хранится в `config/access_token`; не публикуйте его.

```
~/Explorer/bin/explorer start
~/Explorer/bin/explorer estop
~/Explorer/bin/explorer stop
~/Explorer/bin/explorer status
~/Explorer/bin/explorer logs control
```

Кнопка **СТОП** защёлкивает программный стоп базы. Она не отключает питание
сервоприводов и не заменяет физическое отключение питания. На старте стоп включён.
При потере браузера команда движения истекает через 250 мс. Независимый процесс
watchdog отправляет нулевую скорость при пропадании heartbeat контроллера.
Тайм-аут самой STM32 при потере UART ещё не испытан.

Геймпад на Jetson: SDL `game_controller_node`, L1 — удержание разрешения,
левый стик — перемещение, правый X — поворот, Circle/B — стоп.
Направления и конкретный контроллер ещё не испытаны физически.
Браузер поддерживает аналогичную схему, если доступен Gamepad API.
Управление рукой через геймпад ещё не реализовано.

## Службы и восстановление

`explorer.target` включён для автозапуска пользователя vlad (linger включён).
Службы: `explorer-mcu`, `explorer-control`, `explorer-watchdog`, `explorer-state`,
`explorer-ekf`, `explorer-camera`, `explorer-perception`, `explorer-llm`,
`explorer-web`, `explorer-oled`, `explorer-gamepad`, `explorer-geometry`,
`explorer-slam`, `explorer-mapview`.

Логи: `journalctl --user -u explorer-<имя>`. При трёх сбоях за минуту
служба прекращает автоматические перезапуски. После исправления причины:

```
systemctl --user reset-failed explorer-<имя>
systemctl --user restart explorer-<имя>
```

Старые проекты сохранены. Старый контейнер `explorer-micro-ros` остановлен,
автоперезапуск отключён. Не запускайте его одновременно с `explorer-mcu`:
они используют один UART. Прошивка STM32 не менялась.

## Что работает и что осталось

Работают: нативный Jazzy micro-ROS Agent, свежие данные обоих лидаров/IMU/одометрии/
батареи, OLED, совмещённые RGB/depth и intrinsics, EKF, TensorRT YOLO26n,
кратковременное сопровождение объектов, оценки координат относительно камеры,
SQLite-наблюдения, локальная Qwen3.5-2B с ограниченными инструментами и разовым
визуальным анализом, защищённый ключом браузерный интерфейс.

Позиции объектов относительно **робота/карты не откалиброваны**. Имена детектора
и ответы VLM — гипотезы, не разрешение на захват или утилизацию вещей.
Глубина в центре рамки — оценка поверхности, не готовая поза захвата.
Изображение передаётся JPEG; WebRTC пока не реализован.

SLAM Toolbox строит предварительную карту по двум лидарам; карта видна в браузере.
Положение лидаров взято из модели M3 Pro и приблизительно согласуется со статическими
сканами. Виртуальные лучи имеют приближённое начало; для очистки costmap нужно
использовать исходные сканы с реальными центрами. Геометрия ещё не откалибрована.
Nav2 установлен, но автономная навигация, frontier exploration,
планирование руки, захваты, перенос и укладка ещё не реализованы и не испытаны.
Режимы ASSISTED/AUTONOMOUS в интерфейсе только переключают арбитраж; миссии недоступны.
Нет подтверждённой обратной связи суставов. Калибровочные флаги остаются false.
Не включайте их вручную вместо измерений. Максимальные скорости не измерены.
Перезапуск служб проверен; холодная загрузка пока не испытана.

Короткие импульсы вперёд, влево и против часовой стрелки выполнены: пользователь
подтвердил направления и остановки. Логи в `data/base-probe-*.json`, результаты
в `config/verification.json`. Масштаб расстояний и углов ещё не измерен.
Следующий физический этап: тайм-аут MCU, масштаб колёс, измерение TF лидаров,
поза/оси/нули руки и крепление камеры. Только затем разрешать движение и миссии.

## Версии компонентов

- Orbbec SDK 1.10.37 / wrapper 1.5.22; камера RD1014, RGB/depth 15 FPS,
  выравнивание глубины в `camera_color_optical_frame`.
- YOLO26n ONNX из официального Ultralytics v8.4.0, TensorRT FP16 собран на Jetson.
- Qwen3.5-2B Q4_K_M + F16 vision projector, контекст 3072, максимум 512 image tokens.
  VLM вычисляется только по запросу. Модель не имеет доступа к сырым приводам.
