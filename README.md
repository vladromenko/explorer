# Explorer на Jetson

Каталог: `/home/vlad/Explorer`. Основные службы работают на роботе без Mac и облака.
**Физический ввод в эксплуатацию не закончен. Это ещё не готовый автономный манипулятор.**

## Управление и остановка

Панель: `http://explorer.local:8080` или `http://192.168.0.177:8080`.
`~/Explorer/bin/explorer url` выводит ссылку с ключом. Ключ: `config/access_token`.

```
~/Explorer/bin/explorer start
~/Explorer/bin/explorer estop
~/Explorer/bin/explorer stop
~/Explorer/bin/explorer status
~/Explorer/bin/explorer logs control
```

СТОП защёлкивает программный стоп базы и отменяет автономный режим. Он не отключает
питание сервоприводов. На старте стоп включён. Браузерные команды истекают за 250 мс;
отдельный watchdog подаёт нулевую скорость при пропадании контроллера.

Геймпад: L1 удерживать; левый стик — перемещение, правый X — поворот; Circle/B — стоп.
Подключение к Jetson использует SDL; браузерный Gamepad API может требовать HTTPS.
Конкретный геймпад и управление рукой физически не проверены.

## Что установлено

- Нативный Jazzy micro-ROS Agent; два лидара, IMU, энкодеры, батарея и OLED.
- Совмещённые RGB/depth Orbbec; TensorRT YOLO26n; оценки положения в системе камеры.
- EKF и SLAM Toolbox; предварительная карта, маршруты, сохранение PGM/YAML/posegraph.
- Nav2 с боковым ходом, локальными препятствиями и перепланированием; задания,
  отмена, выбор границ исследования, сохранение базовой точки с привязкой к карте.
- Локальная Qwen3.5-2B, разовый визуальный анализ, ограниченные инструменты, SQLite.
- MoveIt 2, эталонная модель руки, расчёт FK/IK и проверка пересечений без исполнения.

Кнопки движения и задания ограничены проверками. Навигационные службы публикуют
только `/explorer/nav_cmd_vel`; к MCU команды отправляют контроллер и watchdog.
Задание требует свежего разрешения, правильного режима, исправных датчиков,
проверенной геометрии, локализации и защиты связи. Ручной ввод прерывает автономию.
Старые задания после перезапуска не возобновляются.

Сохранённые точки нельзя использовать в другой системе координат карты. Загрузка
posegraph ещё не подтверждает локализацию; при переносе робота нужна её проверка.
Карта с текущей стоянки — фрагмент помещения. Отсутствие доступной границы не считается
доказательством полного исследования комнаты.

## Подтверждено / ограничения

Направления коротких импульсов вперёд, влево, против часовой стрелки и остановки
подтверждены пользователем. Масштаб перемещения, максимальные скорости, геометрия
лидаров и камера относительно руки ещё не откалиброваны.

**Тест паузы команд выявил продолжение движения на протяжении 0,82 с до явного нуля.**
Это проверка возраста команды при живом Agent, а не тест разрыва UART. Короткий
тайм-аут STM32 не подтверждён; остановка при полном разрыве связи ещё не испытана.

Через текущий ROS API нет измеренных положений суставов. В vendor-примере есть
чтение servo UART внутри STM32, но оно не выведено в доступный Jetson интерфейс.
Эталонная CAD-модель также имеет нерешённые пересечения деталей захвата. Поэтому
реальные движения руки, быстрые скорости, захват, перенос и укладка не разрешены.
Заданные углы не подменяются измеренными. Фото с номерами суставов сохранено как
справочная информация, а не калибровка углов.

Объекты пока имеют координаты только относительно камеры. Детектор/VLM дают гипотезы,
не разрешение на захват. Навигация к предметам и сбор вещей физически не выполнены.
Видео передаётся JPEG; WebRTC не установлен. Холодная загрузка не испытана.
Калибровочные флаги `config/commissioning.json` нельзя включать вместо измерений.

Провод питания отключён пользователем. Logitech C920 используется только при настройке;
при блокировке Mac свежие кадры недоступны. Основная камера на роботе продолжает работать.

27 автоматических проверок прошли. Под нагрузкой визуального ИИ максимальный интервал
контроллера составил 22,6 мс (обычно 20 мс). Живые проверки и ограничения записаны
в `config/verification.json`; сырые журналы — в `data/`.

## Службы и восстановление

Автозапуск: пользовательский `explorer.target`, linger включён.
Службы `explorer-`: mcu, watchdog, control, state, ekf, camera, perception, llm,
web, oled, gamepad, geometry, slam, mapview, planning, navigation.

Логи: `journalctl --user -u explorer-<имя>`. После устранения причины сбоя:
`systemctl --user reset-failed explorer-<имя>` и `systemctl --user restart explorer-<имя>`.
Старые проекты сохранены. Старый Docker Agent остановлен; не запускайте его вместе
с `explorer-mcu`, поскольку они используют один UART.

Прошивка не менялась. Совпадающие baseline/readback и recovery сохранены в
`vendor/firmware_baseline/`; SHA-256 — в `config/components.json`.
Исходники полного работающего образа не найдены. Прошивка arm-only из MILO не подходит.
Для замены MCU нужна объединённая проверенная версия с обратной связью суставов,
защитой команд/связи и подтверждённым восстановлением; текущая процедура ROM recovery
требует физического переключения BOOT0. Непроверенный образ не загружался.

Версии/хеши: `config/components.json`, `config/moveit_packages.json`.
MoveIt установлен в пользовательский каталог; воспроизведение —
`bin/install-moveit-user.py`, затем `bin/build-arm-model.py`.
