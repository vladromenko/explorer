# Доступ к Explorer

Подключение к роботу выполняется по SSH:

```bash
ssh explorer
```

Панель ручного управления открывается на MacBook по адресу `http://explorer.local:8080` или по текущему IP робота. Токен панели хранится только на роботе в `config/access_token` и не включается в Git.

Для работы не нужны внешние облачные сервисы: MacBook и Explorer должны находиться в одной локальной сети.
