# Доступ к Explorer

Подключение к роботу выполняется по SSH:

```bash
ssh explorer
```

Панель ручного управления открывается без пароля на MacBook по адресу `http://explorer.local:8080` или по текущему IP робота. SSH также настроен по ключу: команда `ssh explorer` не запрашивает пароль пользователя.

Для работы не нужны внешние облачные сервисы: MacBook и Explorer должны находиться в одной локальной сети.
