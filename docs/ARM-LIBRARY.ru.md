# Позиции руки и предпросмотр движения

Библиотека использует существующие CAD/URDF, FK/IK и MoveIt-планировщик Explorer. Она сохраняет именованные позы и статические сцены, показывает суставные, Cartesian и случайные достижимые пути. Её вызовы не отправляют команды приводам. Предпросмотр не подтверждает физическое достижение, калибровку камеры или измерение положения сервопривода.

## Исходные позиции

Позиции камеры читаются непосредственно из `src/camera_views.py:VIEWS`: `camera_forward`, `camera_left`, `camera_right`. Во всех этих позициях сохраняется текущая команда раскрытия захвата №6. `factory_reference` берётся из `config/factory-arm-startup.json`, включая установленную там команду захвата. При наличии исторического отчёта доступна `historical_observed_home`: это поза из старой визуальной проверки, а не новая аппаратная приёмка.

Новых углов «перевозки» или «предзахвата» библиотека не придумывает. Свою позицию можно сохранить из текущего состояния. Проверяются существующие механические пределы и столкновения с моделью/полом для пяти форм захвата. Флаг наблюдения человеком сохраняется отдельно от признака измеренного положения, который остаётся ложным.

## Сцены

Сохранённая сцена содержит до 32 явно заданных прямоугольных препятствий. Их `center` и `size` задаются в метрах в системе `base_footprint`. Одинаковые ID, нулевые/отрицательные размеры и нечисловые значения отклоняются. Каждая сцена передаётся штатному MoveIt-планировщику, который учитывает её при расчёте. Это статический эскиз: камера не превращает его автоматически в измеренную карту помещения.

## Предпросмотры

Суставный предпросмотр сохраняет весь возвращённый MoveIt путь и траекторию. Именованная поза сначала разрешается относительно текущего захвата, затем проходит тот же планировщик.

Cartesian-предпросмотр разбивает прямую в XYZ на точки с шагом по умолчанию 1 см. Для каждой точки используется существующий локальный IK с пределом изменения сустава 10°, затем существующий MoveIt для проверки пути с препятствиями. Интерполяция полученного пути проверяется с шагом до 0,5°: отклонение от заданной Cartesian-линии больше 3 мм отклоняет сегмент. Возвращаются все принятые сегменты, причина отказа и завершённая доля. Пять позиционных осей позволяют позиционный IK с сохранением roll и близостью к исходной конфигурации; произвольная ориентация 6D не обещается. Захват №6 не участвует в позиционном IK.

Случайный предпросмотр генерирует локальные цели вокруг текущих суставов в существующих пределах. Начальный `seed` делает результат воспроизводимым. Каждая цель проверяется FK и существующим планировщиком. По умолчанию возвращаются до трёх подходящих вариантов из 24 попыток; хват сохраняется. Кнопка предпросмотра не запускает случайное движение.

Один Cartesian-предпросмотр ограничен количеством точек и сроком проверки. Штатный MoveIt worker имеет свой ограниченный тайм-аут; уже начатый его вызов завершается по этому тайм-ауту, после чего просроченный результат отклоняется. Это ограничение процесса предпросмотра, а не срок действительности физической команды.

## Файлы и API

- `src/arm_library.py`: `ArmLibrary(root, model_callback, planner_instance)`; `catalog`, `save_pose`, `named_pose`, `save_scene`, `scene`, `preview_joint`, `preview_named`, `preview_cartesian`, `preview_random`.
- `data/arm-library.json`: сохранённые пользовательские позиции и сцены, атомарная запись, версия схемы 1.
- `tests/test_arm_library.py`: проверка сохранения, границ, передачи сцены, Cartesian-коридора, IK-отказа, случайных целей и отсутствия разрешения выполнения.

Поле `execution_allowed=false` означает, что результат предназначен для просмотра. Реальное выполнение, если оно отдельно запрошено, должно повторно проходить существующий исполнитель с актуальным состоянием, владельцем управления и действительными ограничениями. Библиотека этого разрешения не выдаёт.
