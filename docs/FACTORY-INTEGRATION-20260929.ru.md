## Неудачная проверка восстановления связи

После остановки при приостановленном агенте замечен дополнительный небольшой сдвиг. Перезапуск агента не доказал исправление. Экспериментальная автоматическая перезагрузка агента снята; транспортные эксперименты на полу остановлены. По анализу кадров вторая небольшая подвижка произошла до запуска нового агента. Поэтому версия «только повтор очереди Jetson» не доказана.

В заводском коде два пути завершения вызывают Motion_Stop(STOP_FREE): 0x08000d68 и 0x0800c41c задают аргумент 0 перед вызовом 0x080043b0. Это возможное объяснение дополнительной подвижки после снятия торможения, но не доказанный физический диагноз.

В одном журнале final_velocity брался из последнего УСТАРЕВШЕГО сообщения после исчезновения телеметрии. Это не измерение конечной скорости. Скрипт исправлен: при возрасте источника >=0,5 с final_velocity=null, final_telemetry_fresh=false. Исходные журналы не перезаписывались.

## Подтверждённая ошибка моего патча 1.0

`releases/M3PRO-Factory-ChassisWatchdog-1.0/source/watchdog_patch.S` ошибочно называет 0x24001a64 FACTORY_PING_COUNT, а 0x080019a9 — FACTORY_PING_CHECK. В действительности:

- 0x08000dfc увеличивает счётчик; исходный порог — 10, период приложения — 10 мс.
- 0x080019a8 измеряет напряжение, сравнивает его с 10,3 В, считает последовательные низкие значения.
- Сброс счётчика в каждом cmd_vel мешает периодическому опросу батареи. Новые сообщения battery могут не означать новую выборку ADC.

Дефект воспроизведён на машинных байтах установленного BIN 1.0 с моками функций платы: 1100 циклов при регулярных cmd_vel дали 0 вызовов проверки батареи.

## Исправление, только на компьютере

`firmware/factory_patch_1_1/` содержит кандидат, который разделяет поля существующего слова счётчика, сохраняет исходную частоту батарейной проверки, ограничивает возраст команды 26 циклами, требует нулевую команду после истечения, отклоняет NaN/Inf, оставляет торможение при завершении задач. Арм-протокол и заводские драйверы сохранены.

Полный BIN: `52c914ec6bf4664e7a8564202f593d8efa5f6851cdd2aec9e3d7794a5ea128dc`, 1 МиБ. Пакет `releases/M3PRO-Factory-ChassisWatchdog-1.1-rc1`. На контроллер НЕ записан. ELF/MAP относятся к патчу; BIN/HEX содержат весь заводской образ с изменениями. Не выдавать это за полный исходный проект производителя.

ASan/UBSan C-тесты пройдены. Функции Thumb исполнены с моками платы; проверены ветвления хуков, ABI float, стек, поля RAM, независимая периодичность батареи, истечение и нулевая команда восстановления. Ограничение Unicorn: M7-модель не исполняет FP64 compare; использован A15 для FP64 с явной моделью PRIMASK. Планировщик и реальная плата этими тестами не проверены.

Twist не несёт исходную временную метку. Нельзя математически доказать свежесть ненулевой команды после доставленной нулевой только по этому сообщению. Поэтому физический тест восстановления остаётся открытым даже после успешных компьютерных тестов.

Пройдено 12 компьютерных тестов gamepad/holonomic, включая 5 новых регрессионных. Проверен подключённый USB-приёмник и нейтраль всех четырёх осей.
