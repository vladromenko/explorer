# Установка и восстановление

Основная копия проекта на MacBook: `~/Desktop/Projects/17_Explorer`.

На роботе проект расположен в `/home/vlad/Explorer`. После копирования кода установите и перезапустите минимальный набор служб:

```bash
cd /home/vlad/Explorer
sudo ./bin/install-services.py
```

Должны работать только:

- `explorer-mcu.service`
- `explorer-watchdog.service`
- `explorer-control.service`
- `explorer-power.service`
- `explorer-camera.service`
- `explorer-camera-cache.service`
- `explorer-web.service`

Проверьте камеру и свежесть датчиков в панели. Физическую проверку движения выполняйте только на свободной площадке: сначала убедитесь, что STOP включён, затем выберите клавиатуру или геймпад, подтвердите присутствие и включите ручное управление.

Прошивка контроллера и инструкция к ней находятся в `firmware/`. Перед перепрошивкой сохраните текущую рабочую версию и не меняйте механику, калибровку сервоприводов или геометрию без отдельной задачи.
