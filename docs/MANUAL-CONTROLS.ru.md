# Управление Explorer

## Перед началом

1. Откройте веб-панель Explorer.
2. Отметьте **«Робот и провод расположены безопасно, я наблюдаю»**.
3. Выберите **«Клавиатура»** или **«Джойстик»**.
4. Нажмите **«Разрешить ручное управление»**.

## Клавиатура

### Шасси

| Клавиша | Действие |
|---|---|
| `W` | Ехать вперёд |
| `S` | Ехать назад |
| `A` | Mecanum-смещение влево |
| `D` | Mecanum-смещение вправо |
| `Q` | Поворот против часовой стрелки |
| `E` | Поворот по часовой стрелке |

### Cartesian-перемещение руки

| Клавиша | Действие |
|---|---|
| `R` / `F` | Перемещение захвата по оси X |
| `←` / `→` | Перемещение захвата по оси Y |
| `↑` / `↓` | Перемещение захвата по оси Z |

Cartesian-управление само согласует движения нескольких суставов.

### Прямое управление суставами

| Клавиши | Привод | Действие |
|---|---|---|
| `Y` / `H` | Сустав 1 — основание | Увеличить / уменьшить угол |
| `U` / `J` | Сустав 2 — плечо | Поднять / опустить |
| `I` / `K` | Сустав 3 — локоть | Увеличить / уменьшить угол |
| `T` / `G` | Сустав 4 — кисть | Увеличить / уменьшить угол |
| `Z` / `C` | Сустав 5 — вращение кисти | В одну / другую сторону |
| `V` / `B` | Сустав 6 — захват | Открыть / закрыть |

### Скорость и остановка

| Клавиша | Действие |
|---|---|
| `Shift` | Точный медленный режим, пока клавиша удерживается |
| `Пробел` | Общий STOP |
| `Enter` | Возобновить управление после STOP |

Перед `Enter` необходимо отпустить все клавиши движения.

Можно одновременно удерживать команды шасси и руки, например `W + U + B`.

## Джойстик

### Обычный режим — шасси

| Орган управления | Действие |
|---|---|
| Левый стик `↑/↓` | Вперёд / назад |
| Левый стик `←/→` | Mecanum-смещение влево / вправо |
| Правый стик `←/→` | Поворот шасси |

Скорость пропорциональна отклонению стика. Возле центра отклик смягчён 50-процентной экспоненциальной кривой.

Текущие максимальные скорости:

- вперёд/назад — `0,8 м/с`;
- вбок — `0,72 м/с`;
- поворот — `1,67 рад/с`.

### Режим руки — удерживать `R1`

| Орган управления | Действие |
|---|---|
| Крестовина `←/→` | Сустав 1 — основание |
| Крестовина `↑/↓` | Сустав 2 — плечо |
| Правый стик `↑/↓` | Сустав 3 — локоть |
| Правый стик `←/→` | Сустав 4 — кисть |
| `Y` / `A` | Сустав 5 — вращение кисти |
| `L2` / `R2` | Открыть / закрыть захват |

Во время удержания `R1` левый стик продолжает управлять шасси. Поэтому можно одновременно ехать, двигать рукой и работать захватом.

### Служебные кнопки

| Кнопка | Действие |
|---|---|
| `X` | Переключить обычный и точный режим |
| `B` | Общий STOP |
| `START` | Возобновить управление после STOP |
| `SELECT` | Не назначена |
| Нажатия стиков | Не назначены |
| `MODE` | Контроллер не передаёт событие |

После STOP полностью отпустите стики, крестовину и кнопки движения, затем нажмите `START`.
