# Удалённое управление Explorer с телефона

## Однократная настройка

1. Авторизуйте `explorer-robot` по ссылке, которую показывает команда `bin/remote-access login`.
2. Установите приложение Tailscale на телефон и войдите в тот же аккаунт.
3. В домашней сети откройте `http://explorer.local:8080/mobile`. Если имя не открывается, используйте локальный адрес, показанный командой `/home/vlad/Explorer/bin/explorer mobile-url`.
4. Вне домашней сети включите Tailscale на телефоне. В Telegram-боте Explorer можно отправить `/mobile`: бот вернёт приватный адрес панели.

Локальный Wi-Fi и Tailscale — два равноправных способа открыть одну панель. Tailscale не требуется, когда телефон и Explorer находятся в одной обычной Wi-Fi сети. Оба адреса используют один и тот же ключ доступа.
4. Откройте адрес, введите обычный ключ web-панели Explorer и при желании добавьте страницу на домашний экран телефона.

Адрес доступен только устройствам вашего tailnet. Tailscale Funnel и публичный доступ не используются.

## Управление

Кнопка направления движет шасси только пока палец удерживается. Отпускание, сворачивание страницы, потеря свежего изображения или сетевой отказ прекращают отправку команд. Красная кнопка включает STOP. Перед продолжением нажмите «Разрешить движение».

Рука получает один конечный шаг 5° на одно нажатие. Для захвата предусмотрены отдельные кнопки открытия и закрытия. Телефонный интерфейс не отправляет непрерывную скорость суставам.

После полного включения робот сам один раз задаёт исходную позу руки 90°. Если исходная поза потеряна, в телефонной панели нажмите «Повторно вывести руку в 90°», наблюдая за свободным пространством вокруг манипулятора.

Принятая на 30 сентября калибровка разрешает ручное всенаправленное шасси, конечные команды руки и запись демонстраций с hand-eye. Она не превращает расчётные углы суставов в измеренные и не подтверждает удержание предмета. Статус оставшихся калибровок смотрите в основной панели Explorer.

## Обучение

Выберите готовую цель либо заполните собственную. Для одной модели сохраняйте одинаковое название задачи. Начните запись и последовательно отмечайте стадии: поиск и поездка, захват, перевозка, размещение. Успех отмечайте только после фактического размещения предмета.

После 10 успешных полных показов можно запустить пробное обучение; рабочий набор обычно содержит 30–100 показов. Обучение требует STOP, достаточного питания и неподвижного робота.

## Два VPN на Jetson

AmneziaWG используется Telegram-сервисом как локальный HTTPS-прокси. Установленный Tailscale работает в userspace-режиме и не добавляет интерфейс, маршрут по умолчанию или DNS на Jetson. Поэтому оба сервиса рассчитаны на одновременную работу; переключать их для обычного использования не требуется.

На iOS и Android обычно может быть активен только один системный VPN. Во время удалённого управления включайте Tailscale на телефоне. Это ограничение телефона не отключает AmneziaWG и Telegram на самом роботе.

## Переход через Telegram

- `/camera` или кнопка «Камера» возвращает ссылки на полную панель по домашней сети, локальному IP и Tailscale.
- `/mobile` или кнопка «Телефон» возвращает телефонную панель с камерой, шасси, рукой, захватом и записью обучения.
- `/learn` показывает количество показов и следующее упражнение для каждого автономного допуска.
- `/status` показывает напряжение, V≈%, CPU/GPU/RAM, максимальную температуру, свежесть датчиков, контроллер, режим, STOP и прогресс автономности.
- `/experiments` сначала объясняет каждый тест. Нажатие выполняет один анализ в режиме observe без движения робота.

Ссылки с ключом выдаются только уже привязанному Telegram-пользователю из allowlist. Не пересылайте сообщение с такой ссылкой.
