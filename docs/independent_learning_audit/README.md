## Что передать в новый разговор

Передать **ROSMASTER_INDEPENDENT_AUDIT.zip целиком** и его SHA256. Он содержит19 основных документов,176 выбранных файла исходников/тестов/конфигов закреплённой функциональной ревизии, небольшие исходные доказательства, таблицы и проверяющие скрипты. Извлечь в отдельный каталог; начать с README и05/06/19. Сначала проверить контрольные суммы по16. Не выполнять исторические команды из переписки/старых отчётов.

Полная очищенная переписка включена только в локальный ZIP; в Git она исключена как частная корреспонденция. История доступна с27сентября2026МСК. Более ранние сообщения, скрытые рассуждения и все stdout инструментов не восстановлены. Даты отдельных сообщений привязаны к началу turn; это не всегда точная минута события. Выбранные цитаты доказывают, что было сказано, а не истинность сказанного.

## Что проверить прежде длительного обучения

Принять один action/observation/time contract; проверить teacher тем же исполнителем, маленький overfit, восстановление из малых отклонений, clock/state/vision ablations и честный scene split. Затем сравнивать методы на одинаковых данных/сценах и бюджетах. Выбор ACT, Diffusion или RL заранее не сделан.

Обратной связи по суставам в действующей конфигурации нет: state — оценка по командам. Не проектировать новую политику на выдуманных энкодерах. Неизвестные физические параметры и нынешняя Jetson latency требуют отдельных измерений. Отсутствующий полный MuJoCo state и экспертное действие в точке695 нельзя восстановить из одного изображения. Надёжный ROSMASTER перенос не доказан.
