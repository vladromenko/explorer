# Explorer: первый тест и управление

Обновлено 28.09.2026. Код на Jetson: `/home/vlad/Explorer`; учебная копия на Mac:
`/Users/vladromenko/Documents/Codex/Explorer`. Панель: http://explorer.local:8080.
Если она запрашивает ключ, в своём SSH-терминале выполните `~/Explorer/bin/explorer url`
и откройте полученную ссылку. Ссылка содержит ключ доступа; не пересылайте её.

## Первый эксперимент без движения

1. Откройте **Эксперименты**. Оставьте профиль **Работа** и режим **Наблюдение сейчас**.
2. Выберите **E02 · Найти предмет**, введите английскую метку, например `bottle`,
   или оставьте поле пустым, чтобы увидеть все текущие гипотезы детектора.
3. Нажмите **Проверить готовность**, затем **Запустить без движения**.
4. **E03** сохранит наблюдение в память. **E04** сравнит поиск по меткам с последними
   ракурсами. Разные одинаковые предметы можно вручную добавить в «Память предметов».
5. Прошлые запуски открываются ниже. Выберите запуск, переключите режим на
   **Повтор сохранённых данных**, запустите снова. Replay использует записанный вход
   и не управляет моторами. **Скачать результат** сохраняет JSON.

Для размеров области предмета раскройте **Выбрать предмет на снимке для E09 / E10**:
сделайте снимок, укажите два противоположных угла, выберите E10 и запустите анализ.
Размеры относятся к ограничивающему прямоугольнику, не к проверенной маске предмета.
Если глубина отсутствует или неоднородна, результата захвата не будет. Замороженный
снимок пригоден для сравнения алгоритма, но не для актуального движения руки.

E05 ранжирует границы известной карты без поездки. E06/E14 показывают порядок навыков
и недостающие допуски. E07/E08/E12/E13 требуют наблюдений/меток; отсутствие данных
даёт «неизвестно» или схему ввода, а не выдуманный успешный опыт. E01 показывает,
почему команда положения ещё не является измерением сустава.

## Telegram

Бот: https://t.me/explorer2020bot. Токен сохранён на Jetson вне Git, бот подключён
через имеющийся приватный прокси. Чтобы привязать именно свой аккаунт:

1. Внизу вкладки **Эксперименты** нажмите **Создать код привязки**.
2. Отправьте показанную команду `/pair …` боту в личном чате в течение пяти минут.
3. Вернитесь в панель, проверьте показанные username и числовой ID.
4. Нажмите **Подтвердить этот аккаунт**. До этого управляющие команды не разрешены.

Меню: Состояние, Камера, Эксперименты, Память, Обучение, Результаты, Остановить.
Кнопки экспериментов одноразовые и действуют 60 секунд. «Камера» открывает ссылку
на локальную панель: пересылка изображений во внешний сервис не включена.
Бот не снимает STOP и не разрешает неподтверждённые физические действия.
Без домашней сети ссылка `explorer.local` может не открываться; это не публичный сайт.

Токен, ранее отправленный в чат, можно заменить через BotFather. Новый вводится
скрыто командой `python3 ~/Explorer/bin/configure-telegram.py`, затем
`systemctl --user restart explorer-telegram`. Токены не вводятся в исходный код.

## Рука, джойстик и обучение

Во вкладке **Рука и обучение** сначала под наблюдением подготовьте руку.
Стартовая поза задаётся за пять секунд; это движение, в отличие от лабораторного анализа.
Кнопки ±2° и режим руки на геймпаде сохраняют прежние ограничения. Нельзя силой вести
включённые сервоприводы рукой: чтение реальной позы для такого показа пока не подключено.

На геймпаде без L1: A выбирает руку, X — шасси, крестовина выбирает сустав.
С L1 правый стик вверх/вниз задаёт один шаг сустава; перед следующим верните его в нейтраль.
B — STOP шасси, SELECT+START удерживать 0,6 секунды — STOP с фиксацией.
Распределение осей для голономного шасси реализовано: левый стик вперёд/боком,
правый — поворот. Физический допуск езды остаётся закрыт из-за отказа остановки
при потере связи с контроллером. На OLED `V≈%` — шкала напряжения, не точный SOC.

Показы: задайте одно название навыка, **Начать показ**, управляйте малыми шагами,
завершите с честной оценкой исхода. Для ACT нужно минимум десять успешных показов;
30–50 разнообразных полезнее одинаковых повторов. Записи хранят команды суставов,
а не подтверждённые измерения. Не помечайте неудачу как успех ради допуска обучения.

Перед обучением выберите профиль **Обучение** в лаборатории. Он требует STOP,
останавливает простаивающие LLM/распознавание речи и разрешает задачу обучения.
Профиль **Эксперимент** допускает поиск и проверку ACT без языковой модели;
**Работа** возвращает обычные функции. Смена профиля при занятой тяжёлой задаче
отклоняется. Службы управления, STOP, питание и датчики не выключаются профилями.
Ограничения памяти systemd и проверка свободной RAM остаются дополнительными барьерами,
но не обещанием отсутствия OOM для произвольной будущей модели.

Обучите ACT, затем сначала посмотрите предложение модели. Наблюдаемый тест
при удержании кнопки — отдельное действие с реальной рукой. В лаборатории можно
сохранить оценку неудачи или вмешательства; E18 предложит следующие условия показов.
Очередь E18 не меняет веса автоматически. Реальных показов и обученного навыка
«поднять носок» на момент этого выпуска нет.

## Голос

Во вкладке **Голос и помощник** доступны запись с USB-микрофона, локальная
расшифровка и озвучивание через динамик. Постоянного прослушивания нет.
Распознавание речи само по себе не является разрешением движения.

## Реальные ограничения и следующий шаг

| Ограничение | Конкретный следующий шаг |
|---|---|
| Нет измеренных углов руки | Получить документированный host-метод чтения через установленную прошивку либо согласовать отдельный интерфейс сервошины; декодер USART3 уже проверен на пакетах |
| При потере канала MCU колёса ранее продолжали движение | Подключить и проверить независимое прекращение тяги; Jetson watchdog не заменяет недоступный STM32 канал |
| Нет сквозного «доехать — взять — принести» | После двух пунктов выше измерить TF/габариты транспортной позы и выполнить один наблюдаемый цикл |
| Telegram ещё не знает владельца | Выполнить четыре шага привязки выше |
| Автовыключение не подключено | При желании выполнить на Jetson `sudo ~/Explorer/bin/install-power-permission.sh` |

Прошивка STM32 и сеть не изменены. Logitech не является обязательной частью
системы; в текущем окружении Mac она не перечислялась как доступное устройство.
Новые физические испытания в этом выпуске не проводились.

## Файлы, проверка, откат

`data/experiments/` — результаты; `data/experiment-captures/` — RGB-D снимки;
`data/experiments.sqlite3` — предметы, наблюдения, история и оценки;
`data/demonstrations/` — показы; `data/learning-jobs/` — обучение и веса.
Это частные данные, они не публикуются в GitHub.

CLI на Jetson: `python3 ~/Explorer/bin/experiment.py E01`.
Программная проверка без движения: `cd ~/Explorer && source bin/env.sh && python3 bin/lab-check.py`.
Подробный отчёт: `data/lab-acceptance.json`; он отделяет задержку ПО от физического торможения.

До выпуска сохранён Git bundle `data/release-checkpoints/before-lab-20260928.bundle`
и закрытый архив настроек. Для отката сначала STOP, завершите запись/обучение,
сохраните текущий код отдельным commit и извлеките bundle в **другую** папку.
Не удаляйте `data/`, веса или секреты и не делайте `git reset --hard` поверх своих изменений.
Старый commit — `3318338`. Возврат старого кода не исправляет аппаратные ограничения.
