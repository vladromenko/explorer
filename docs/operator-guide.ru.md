# Explorer: управление и обучение руки

Обновлено 27 сентября 2026 года. Этот документ описывает фактические возможности установленного ПО и оставшиеся ограничения.

## Открыть панель

На Mac можно дважды нажать «Открыть Explorer.command» из выданных файлов. Он получает ключ по уже настроенному SSH и открывает браузер; ключ не записывается в файл запуска.

На компьютере в той же сети откройте http://explorer.local:8080. Если имя не находится, используйте IP-адрес Jetson. Войдите своим ключом Explorer. Ключ остаётся в текущем сеансе браузера; не отправляйте ссылку с ключом другим людям. На странице есть ссылка «Открыть понятную инструкцию».

Камера, напряжение батареи, состояние датчиков и причины блокировки показываются в панели. Фото Booth для этого не нужен. При отсутствии свежих данных управление недоступно.

## Что готово, а что ещё нет

| Возможность | Состояние |
|---|---|
| Камера, распознавание, телеметрия, предварительная карта | Рабочие службы Explorer; показ зависит от свежести датчиков |
| Геометрия руки и планирование MoveIt | Расчёт и проверка пути доступны; расчёт не означает физическое выполнение |
| Запись коротких показов кнопками панели | Реализована; требует свежей исходной команды руки в текущем включении и наблюдения человеком |
| Геймпад на Jetson | Чтение кнопок, выбор сустава и предложения шагов; движение стиком пока заблокировано |
| Нейросеть обучения | Используется готовый LeRobot 0.6.1, модель ACT; состояние вычислительной проверки видно в панели |
| Самостоятельное хватание носка | Не обучено и не подтверждено |
| Непрерывное движение рукой от джойстика | Не разрешено: потеря радиосвязи и прерывание движения сервопривода не проверены |
| Самостоятельная езда, поиск и подбирание вещей | Физическая калибровка и проверка защиты ещё не завершены |
| Процент батареи и оставшееся время | Неизвестны: нет подтверждённых характеристик аккумулятора и измерения его тока |
| Автоматическое выключение при разряде | Подготовлено, но системное разрешение администратора ещё не установлено |

Прошивка контроллера не менялась. Нажатие «Стоп шасси» останавливает шасси; оно не является подтверждённой остановкой уже выполняемого движения руки.

## Как устроено обучение

Вы показываете действие роботу через управление его рукой. Сохраняются изображение с камеры на руке, заданные углы, следующая команда, время и ваша оценка результата. Изображения с обычной внешней камеры, где человек берёт носок своей рукой, сами по себе не дают роботу соответствующие команды суставов. Поддержки такого обучения по произвольному видео сейчас нет. Не перемещайте включённые сервоприводы рукой силой.

LeRobot обучает ACT по записанным парам «наблюдение — действие». Последние 20% целых показов (минимум два) откладываются для независимой проверки. Неудачные, прерванные, неопределённые и инженерные проверочные попытки не попадают в успешные показы. Предыдущая ручная попытка взять носок не записана как успех.

Сейчас запись рассчитана на отдельные медленные шаги. Номер шага — это порядок решений, а не частота физического движения. Настоящие времена сохранены отдельно. Модель предсказывает один следующий шаг; автоматическое воспроизведение её команд не включено. Это подготовка обучения, а не обещание уже готового автономного навыка.

## Перед показом

1. Зарядите выключенного робота. Отсоедините провод перед передвижением шасси. Не считайте подключённый зарядник доказательством зарядки включённой машины.
2. Поставьте робота устойчиво. Рядом с рукой не должно быть человека, кабелей или твёрдых препятствий. Оператор остаётся рядом и может отключить питание.
3. Включите стоп шасси. Откройте панель и проверьте свежую камеру и батарею.
4. Прочитайте строку готовности руки. Если исходное положение не подтверждено в текущем сеансе или старше 15 минут, запись заблокирована. Перезагрузка не восстанавливает достоверные углы автоматически.
5. При такой блокировке не снимайте её редактированием файлов: требуется закончить физическую проверку исходной позы/обратной связи. В текущей версии нет проверенного автоматического восстановления позы после включения. Это оставшаяся инженерная работа, а не неисправность кнопки записи.

## Записать показ, когда строка готовности разрешает его

1. В верхней панели задайте один навык, например «Поднять носок». Для разных навыков используйте отдельные наборы показов; текущая ACT обучается одному набору за запуск.
2. Поставьте флажок присутствия и нажмите «Начать показ».
3. Выберите сустав: 1 основание, 2 плечо, 3 локоть, 4 наклон кисти, 5 поворот кисти, 6 захват.
4. Кнопка «+ 2°» или «− 2°» задаёт один медленный шаг. Дождитесь завершения. Если движение не соответствует команде, прекратите показ с результатом «Не уверен / прервать». Не продолжайте с неверной исходной позы.
5. По завершении отметьте «получилось» только если носок действительно захвачен, поднят и удерживается. Закрывшаяся клешня или исчезновение носка из кадра не подтверждают успех. При промахе выберите «не получилось».
6. Между показами меняйте положение и ориентацию носка в доступной области, оставляя задачу той же. Не удаляйте неудачи: они нужны для разбора.

Минимум для запуска обучения — 10 успешных показов, не менее трёх шагов в каждом. Практическая начальная цель — 30–50 разнообразных показов. Это не гарантия достаточного качества. Последние проверочные показы должны отличаться положением предмета от обучающих.

## Джойстик

Приёмник подключается к Jetson. Панель читает штатный Linux input, поэтому браузеру не нужны особые права на USB. Сначала включите «Включить панель джойстика».

| Действие | Управление |
|---|---|
| Выбрать режим руки / отключить | A без удержания L1 |
| Выбрать сустав | Крестовина влево/вправо без L1 |
| Предложить шаг +2° / −2° | Удерживать L1, отклонить правый стик вверх/вниз |
| Следующее предложение | Вернуть стик в нейтраль и отклонить снова |
| Стоп шасси | B |
| Стоп с фиксацией | SELECT + START не меньше 0,6 секунды |

Стик пока только выбирает предложение, без движения. Для физического шага используются кнопки панели при доступном показе. Это временный ограниченный режим: полного ручного управления джойстиком пока нет. Закрытие/скрытие вкладки отключает режим. Повторное подключение приёмника не возобновляет управление.

Индикатор «USB-приёмник подключён» не доказывает, что сам пульт включён. Окончательная проверка требует выключить пульт при удерживаемом разрешении, затем отдельно отключить приёмник, и проверить остановку/отсутствие повторного запуска. Повторные сообщения Joy не считаются доказательством радиосвязи.

## Обучить нейросеть

1. Остановите показ. Проверьте счётчик успешных записей и состояние LeRobot.
2. Начните с «Пробное обучение · 1 000 шагов». Это проверка процесса, не достаточный объём для гарантированного навыка.
3. Нажмите «Обучить по показам». Терминал не нужен. Данные остаются на Jetson, автоматической публикации на Hugging Face нет.
4. Следите за состоянием и журналом. Обучение запускается отдельной службой с ограничением памяти и приоритетом ниже управления роботом. Оно не запускается при напряжении ниже 11,5 В, движущейся руке или снятом стопе шасси. При ухудшении питания процесс прерывается.
5. «Остановить обучение» завершает вычисления; сохранённые контрольные точки остаются. Новый запуск создаёт новую версию и не заменяет старую. Автоматического продолжения с прерванной точки в панели пока нет.
6. После обучения программа оценивает ошибку заданных углов на отдельных показах и сравнивает с простым удержанием текущей позиции. Даже малая ошибка не подтверждает захват в реальном мире. При ухудшении результатов добавьте разнообразные показы, а не просто увеличивайте число шагов обучения.

ACT здесь — готовая нейросетевая архитектура LeRobot. Существующая языковая модель отвечает за объяснения и высокоуровневые намерения; она не получает прямого управления сервоприводами. SmolVLA можно рассматривать позднее, после надёжного сбора данных; сейчас она не установлена и не настроена для этой руки.

## Что нужно закончить перед самостоятельным исполнением

Нужны подтверждённая исходная поза и достоверная оценка суставов, калибровка камеры относительно руки, проверенные ограничения захвата, остановка при потерях связи и проверка контакта/удержания предмета. Затем модель должна выдавать цель через проверку MoveIt и местные ограничения питания. Проверка столкновений с моделью самого робота не заменяет карту предметов вокруг руки.

Непроверенная модель не назначается рабочей автоматически. Кнопки «запустить автономный захват» сейчас намеренно нет: подключение обучения к физическому исполнению ещё не завершено. Не включайте флаги калибровки вручную ради обхода этой стадии.

## Батарея и завершение

Панель и маленький экран показывают измеренное напряжение. «--%» означает неизвестный процент, а не нулевой заряд. Рабочие предварительные пороги: предупреждение 11,4 В, ограничение 11,1 В, критический уровень 10,8 В. Под нагрузкой напряжение проседает; это не точный измеритель остатка ёмкости.

При предупреждении завершите работу и поставьте выключенную машину на зарядку. Автоматическое системное выключение пока требует однократной установки разрешения администратором. Подготовленный установщик на Jetson: `/home/vlad/Explorer/bin/install-power-permission.sh`. Его запускают локально с паролем администратора; пароль в чат не вводят. Даже после этого программное выключение Jetson не доказано как отключение всей силовой части робота.

## Где хранятся данные

На Jetson: `/home/vlad/Explorer/data/demonstrations` — оригиналы показов; `data/learning-jobs` — версии наборов, обучение, проверка и журналы; `config/gamepad.yaml` — раскладка пульта. Сохраняйте резервную копию всей папки проекта с данными перед переустановкой. Не отправляйте access_token вместе с архивом.

## Проверка установленной среды

На Jetson проверен полный цикл LeRobot: создание тестового набора, шаг обучения ACT на GPU, сохранение и загрузка модели, оценка на отдельном наборе. Данные теста искусственные, не входят в показы и не доказывают навык захвата. PyTorch выдаёт предупреждение о том, что архитектура Orin 8.7 не включена в официально поддерживаемые этой сборкой; проверен именно путь ACT, совместимость прочих моделей не заявляется.
