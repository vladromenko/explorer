# Проверки выпуска лаборатории

## Что проверено

- 118 unit/regression тестов на Jetson, 14,23 с, все прошли.
- E01–E18 выполнены через авторизованный API в observe; у всех завершён **анализ**.
  Это не результат 18 физических действий. E05 сначала выявил ошибку часов MCU,
  затем заработал после восстановления времени без перепрошивки.
- Неверный ключ — 401; физический режим лаборатории и просроченный запрос — 409.
  Повтор request_id возвращает прежний запуск; изменение параметров с тем же ID отклоняется.
- Replay сохраняет исходный вход; поздние оценки обучения не изменяют прежний результат.
- В живом браузере: авторизация, E01/E05, история, получение RGB-D снимка,
  переключение профилей и возврат в «Работа». Движение из этих тестов не запускалось.
- Telegram: getMe, отсутствие чужого webhook, один poller, меню и connected status.
  Unit-тесты привязки проверяют неверный код, истечение срока и подтверждение чужого ID.
  Реальная переписка с владельцем ещё не пройдена: требуется его личная привязка.
- История Git: 261 blob проверен перед новым commit; совпадений шаблонов секретов,
  приватных data/logs/models/vendor или файлов ключей не найдено. Новые файлы проверяются
  при подготовке публикации. Кадры/демонстрации и VPN-секреты не входят в репозиторий.

## Измерения при штатных службах

20 запросов в каждой серии после установления DDS-соединения:

| Путь | p50 | p95 | максимум |
|---|---:|---:|---:|
| Чтение локального состояния HTTP | 6,85 мс | 10,63 мс | 16,81 мс |
| HTTP STOP → обработчик core, публикация нулевого Twist | 4,47 мс | 5,32 мс | 5,86 мс |

Ответ core явно содержит `mcu_acknowledged=false`. Это **не** время прихода пакета
в контроллер, остановки двигателя или торможения корпуса. Telegram RTT в эту
серию не входит; без владельца не измерен. Сопоставимой записи «до изменений» нет.

В момент проверки: 3860 MB доступной RAM из 7485, температура 55,94 °C.
Отдельная восьмисекундная серия tegrastats: около 3,44 GB занятой RAM, SWAP 0,
в последних двух выборках ядра CPU 34–48%, GR3D 0% в моменты опроса, температура
около 55,9 °C. Эти выборки не являются стресс-тестом обучения/LLM.
Возраст данных последней проверки: scan0 32 мс, scan1 150 мс, IMU 83 мс,
одометрия 74 мс, батарея 522 мс. Частота свежего contact tracking 100–150 мс
не подтверждена, поэтому реактивный контактный цикл не разрешён.

Полные частные результаты остаются на Jetson в `data/lab-acceptance.json`,
`data/lab-resources.log`, `data/tests-lab-release.log`; исходники проверок —
`bin/lab-check.py`, `tests/`.

## Что этим выпуском не подтверждено

- Измеренные углы: в активном `/robotio` нет read service; `/arm6_feedback` без
  издателя. Vendor `get_arm_position` возвращает командный cache. Декодер USART3
  протестирован отдельно, но реальный транспорт чтения не подключён.
- Остановка при потере канала MCU ранее провалилась. Допуск автономной езды
  остаётся false; дополнительные опасные floor-тесты не повторялись.
- Калибровка TF и захвата, силовая модель, пространственная ассоциация предметов,
  сквозной мобильный pick-and-place и реальные обученные навыки не завершены.
- Logitech в окружении Mac не была доступна. Встроенная RGB-D работает.
- Автовыключение не установлено по предыдущему решению владельца.

Состояние после проверок: STOP, нулевые скорости, профиль «Работа»; автоматического
возобновления движения, обучения и старых Telegram-команд нет.

## Дополнительная проверка шасси

`bin/check-chassis.py` проверил восемь направлений/сочетаний: вперёд, назад, боком
влево/вправо, оба поворота, диагональ и диагональ с поворотом. В копии программного
контроллера каждое направление остановлено по TTL, препятствию и устаревшему датчику.
Это проверка алгоритма, не вращение колёс. Флаги на диске не изменялись.

На живых датчиках получена map-поза, 11 границ исследования и два реальных Nav2
маршрута из трёх рассмотренных — 18 и 11 точек. Третий корректно отклонён планировщиком
как не имеющий безопасного пути (208). Между сканами двух лидаров 34 мс.
`data/chassis-acceptance.json` сохраняет результаты. Ни одной команды езды скрипт
не отправляет, STOP остаётся включён. Это закрывает программную проверку цепочки
стики → ограничение → датчики/TF → планировщик, но не физическую приёмку шасси.
