Подготовка переводит руку в стартовую позу за 5 секунд. Выполняйте только при свободном пространстве и под наблюдением.

Кнопка задаёт один короткий шаг на 2° с заданной длительностью 0,15 секунды. Дождитесь окончания и осмотрите руку перед следующим. Можно управлять без записи; «Начать показ» включает сохранение примеров. «Стоп шасси» не прерывает уже отправленное движение сервоприводов. Углы сохраняются как заданные, а не измеренные.

Джойстик

Проверяю приёмник…

Без L1: A — выбрать режим руки; крестовина влево/вправо — сустав. С L1: правый стик вверх/вниз — один шаг на 2°. Верните стик в нейтраль перед следующим шагом. B — стоп шасси. SELECT + START на 0,6 с — стоп с фиксацией.

При готовой руке стик отправляет один ограниченный шаг. Удержание не повторяет движение. Непрерывное управление и езда пока заблокированы до проверки потери связи. Соединение USB не означает наличие радиосвязи.
