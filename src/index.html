Открыть понятную инструкцию ↗

После включения задайте исходную позу вручную. Сначала поддержите руку: первая кнопка отключит удержание. Для установленного образа звенья вертикально вверх, захват приоткрыт примерно на 1,5 см (159,5° по заводской шкале).

После включения удержания уберите руки из зоны движения. При сбросе исходной позы повторите установку; старые команды не возобновляются.

Для robotio кнопка принимает выставленную вами позу 90° всех шести приводов без движения. Нажимайте только когда поза действительно выставлена. Положение далее расчётное; при сбросе контроллера задайте его заново.

Для сустава 6: «−» раскрывает пальцы, «+» сжимает. Точное раскрытие для текущей настройки ещё не откалибровано. С предметом останавливайте сжатие при контакте; сила не измеряется.

Кнопки ±2° задают ручной шаг; длительность рассчитывает исполнитель. При расчётных координатах подтверждается передача команд, а физическое достижение оценивается наблюдением, а STOP запрашивает отмену движения. «Начать показ» сохраняет изображения, команды и источник положения. Сила контакта с предметом не измеряется.

Джойстик

Проверяю приёмник…

Без L1: X — шасси (стики в нейтрали), A — суставы руки, Y — перемещение захвата по X/Y/Z; крестовина влево/вправо — сустав или ось. Захват — сустав 6. С L1: правый стик вверх/вниз — один шаг на 3°. Верните стик в нейтраль перед следующим шагом. В режиме шасси с L1: левый стик — вперёд/назад и боком, правый по горизонтали — поворот. B — стоп робота. Отпускание L1 отменяет дальнейшие команды руки; уже отправленный короткий шаг может завершиться. SELECT + START на 0,6 с — стоп с фиксацией.

При готовой руке стик отправляет один ограниченный шаг. Удержание не повторяет движение. Доступность движения и причины отказа показаны в состоянии механизмов. Соединение USB не означает наличие радиосвязи.

Переместить захват по направлению

Один расчётный шаг около 5 мм относительно корпуса: X — вперёд, Y — влево, Z — вверх. Углы каждого сустава меняются максимум на 2°. Геометрия приблизительная; наблюдайте за рукой. Во время записи показов используйте управление суставами.

Перевести руку в позу через MoveIt

Введите углы суставов 1–5 или подставьте текущую позу, затем рассчитайте путь. Захват сохраняет свой угол. Для движения удерживайте кнопку и наблюдайте за рукой. Каждый шаг повторно проверяется на пересечение с роботом и полом; препятствия вокруг руки проверяет наблюдатель.

Показ целой задачи: подъехать → взять → отвезти → положить

Записывает синхронные кадры, команды всех суставов и шасси, одометрию, лидары и этап действия. Тип и размер предмета сохраняются вместе с показом, чтобы сравнивать перенос навыка.

Полных показов ещё может не быть. Используйте одно название навыка и меняйте предметы, ракурсы и стартовые позиции.

Конечное движение руки и захвата
Для суставов 1–5 используйте углы из блока MoveIt выше. Здесь можно выполнить один конечный путь без удержания кнопки. На новом контроллере сохраняется полный путь MoveIt; STOP отменяет его исполнение. В CommandOnly завершение команд не является измеренным достижением позы. Контакт с предметом требует отдельного наблюдения.
30° — раскрыт; 160° удерживал проверенный носок; 170° — визуально закрытый пустой захват. Сила не измеряется: одинаковый угол не гарантирует захват любого предмета.
